# Persian-AROPL

سایت سینمایی فارسی AROPL با **TinaCMS** برای ویرایش محتوا و استقرار روی **Cloudflare Workers**.
The original site (HTML/CSS/JS) is preserved exactly — design, colours, fonts, animations,
3D book effects, desktop/mobile UI, Study, Books, YouTube, TikTok LIVE — with TinaCMS added
on top as a visual `/admin` panel.

## Architecture (unchanged deployment model)

```
public/            ← the original static site, untouched design
  index.html       ← fills Books / YouTube / TikTok / text from injected JSON
  study.html       ← Study sections rendered from content/study/*.json at build time
  assets/          ← css, js, images, pdf (original files)
  admin/           ← TinaCMS SPA (generated by `tinacms build`)
content/           ← JSON content edited in TinaCMS
  books/*.json     ← Books (cover, title, description, PDF / audio / official links)
  youtube/*.json   ← YouTube blocks + video lists (title, url, thumbnail, cta)
  tiktok/*.json    ← TikTok profile metadata ONLY (username, name, avatar, url, language, order, featured)
  study/*.json     ← Study sections (FA + EN) with paragraphs, subheadings, quotes, final note
  settings/site.json ← general site text + TikTok API base + refresh interval
tina/config.ts     ← TinaCMS schema (5 collections)
scripts/build-content.py ← regenerates tiktok-accounts.js, config.js and renders Study HTML
worker/index.js    ← Cloudflare Worker entrypoint (static assets + /health + optional status proxy)
wrangler.jsonc     ← Worker + assets configuration
```

**TikTok LIVE is unchanged.** LIVE/OFFLINE detection still comes from the existing backend
(`TIKTOK_API_BASE/api/status`, polled every 30 s by `assets/js/tiktok-live.js`). TinaCMS only
manages static profile metadata; it never touches live detection.

## Local development

```bash
pnpm install
pnpm dev            # Tina dev server + wrangler dev
# site:  http://localhost:8788/
# admin: http://localhost:8788/admin/
```

`pnpm build` → `tinacms build --skip-cloud-checks --local` + `scripts/build-content.py`.

## Editing content

Open `/admin` (mobile or desktop). Five collections, no HTML/CSS/JS/JSON editing needed:

- **تنظیمات سایت — Site Settings** (general site text, hero, section headings, TikTok API base)
- **کتاب‌ها — Books**
- **ویدیوهای یوتیوب — YouTube** (per block: channel card + video list)
- **حساب‌های تیک‌تاک — TikTok Profiles** (username, display name, avatar, profile URL, language, order, featured)
- **مطالعه — Study** (FA + EN sections built from paragraph / subheading / quote / final-note blocks)

## Environment variables (NEVER commit real values)

Copy `.env.example` → `.env` locally, and set these in Cloudflare → Worker → Settings:

| Variable | Where | Purpose |
| --- | --- | --- |
| `NEXT_PUBLIC_TINA_CLIENT_ID` | build time | TinaCloud client ID |
| `TINA_TOKEN` | build time | TinaCloud content (read) token |
| `GITHUB_BRANCH` | build time | branch TinaCMS commits to (defaults to `main`) |
| `TIKTOK_API_BASE` | runtime var | existing TikTok LIVE backend base URL |
| `CF_API_TOKEN` | CI only | Cloudflare deploy token (GitHub Actions, optional) |
| `CF_ACCOUNT_ID` | CI only | Cloudflare account id (optional) |

`.env`, `.dev.vars`, `wrangler.local.toml` and all tokens are git-ignored. No secret is
hard-coded anywhere in `public/` or `worker/`.

## Deploy to Cloudflare Workers

Workers Builds (git-based) is the recommended path:

1. Cloudflare → Workers & Pages → Create → Workers → Import a repository → `Persian-AROPL`.
2. Build command: `npm run build:cloud` · Deploy command: `npx wrangler deploy`.
3. Worker → Settings → Build → Variables and Secrets: `NEXT_PUBLIC_TINA_CLIENT_ID`, `TINA_TOKEN`, `GITHUB_BRANCH`.
4. Worker → Settings → Variables: `TIKTOK_API_BASE` (or keep the value in `wrangler.jsonc` vars).
5. In TinaCloud (`app.tina.io`) set the project **Site URL** to the worker URL, e.g. `https://persian-aropl.<account>.workers.dev`,
   so `/admin` login works against the correct origin.

Or from the CLI: `npx wrangler secret put TINA_TOKEN` etc., then `npm run deploy`.

The site answers on the Worker root and TinaCMS on `<worker-url>/admin`.

## دیپلوی Cloudflare Pages (اتصال به گیت)

Cloudflare Dashboard → Workers & Pages → Create → Pages → **Connect to Git** → انتخاب ریپوی `alirezaiwisi1/Persian-AROPL`:

- **Framework preset:** None
- **Build command:** `npm run pages:build`
- **Build output directory:** `public`
- **NODE_VERSION:** `20` (متغیر محیطی)

**Environment variables (Production):**
- `NEXT_PUBLIC_TINA_CLIENT_ID` = کلاینت ID پروژه Tina
- `TINA_TOKEN` = توکن Read-Only پروژه Tina (فقط در تنظیمات Cloudflare — هرگز در کد نیست)
- `GITHUB_BRANCH` = `main`

بعد از این، هر تغییر در `/admin` تینا → commit به ریپو → دیپلوی خودکار Pages.
